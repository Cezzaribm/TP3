# TP3

Este repositório reúne o código do nosso sistema de biblioteca desenvolvido em Python com SQLAlchemy, estruturado de forma simples e direta em três arquivos: o modelos.py, que define as tabelas e suas relações; o popular.py, responsável por criar e preencher o banco com dados iniciais de teste; e o consultas.py, que executa as principais buscas no sistema.
